# XaCode Android

XaCode — мобильный AI-помощник для вайб-кодинга. В приложении можно обсуждать идеи, проектировать приложения, писать код и создавать ботов через любой OpenAI-совместимый API.

## Первый MVP

- четыре режима: обычный чат, приложение, код и бот;
- локальная история разговоров;
- выбор модели, API endpoint и ключа;
- современный тёмный интерфейс на Jetpack Compose;
- поддержка OpenAI-совместимого формата `/chat/completions`;
- данные остаются в приватном хранилище приложения.

## Запуск

1. Откройте проект в Android Studio.
2. Дождитесь Gradle Sync.
3. Запустите конфигурацию `app` на Android 8.0 или новее.
4. В приложении откройте «Настройки AI», укажите endpoint, модель и API-ключ.

Для локальных серверов можно указать собственный URL. HTTP без TLS разрешён только если система или network security policy устройства это допускает; для реального использования рекомендуется HTTPS.

## Сборка из терминала

```powershell
.\gradlew.bat assembleDebug
```

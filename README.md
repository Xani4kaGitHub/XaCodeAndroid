# XaCode Android

XaCode — мобильный AI-помощник для вайб-кодинга. Просто опишите задачу: XaCode сам понимает, нужно ответить на вопрос, написать код, спроектировать приложение или создать бота.

- автоматическое понимание намерения без ручных режимов;
- локальная история разговоров;
- несколько профилей моделей и быстрый выбор модели для чата;
- DeepSeek, OpenAI, Anthropic, Google Gemini, OpenRouter, AgentRouter, Ollama и собственный API;
- просмотр, скрытие, изменение и защищённое хранение API-ключей;
- проверка подключения прямо из настроек;
- пользовательские инструкции, temperature и параметры reasoning;
- несколько проектов-папок через Android Storage Access Framework;
- обычные чаты и отдельные цепочки чатов внутри каждого проекта;
- просмотр и редактирование файлов, создание файлов и папок прямо в приложении;
- 17 инструментов агента: обзор проекта, чтение, запись, glob/regex-поиск, создание, переименование, удаление, patch, undo, todo, скачивание файлов и запуск Python;
- Markdown-оформление ответов: заголовки, списки, цитаты, таблицы, задачи, ссылки, зачёркивание, формулы и блоки кода;
- встроенный Python 3.13: запуск `.py` из агента и кнопкой Run в редакторе, с возвратом stdout/stderr;
- русский, українська и English для основных экранов с переключением в настройках оформления;
- защищённая сеть: внешний API только через HTTPS, SSRF-защита загрузчика и лимиты ответов;
- отдельные разрешения для удаления файлов агентом, загрузок и выполнения Python;
- создание случайно названного проекта «с нуля» и подключение существующей папки по логике XaCode Desktop;
- кнопка копирования ответа, счётчик токенов, вызовов инструментов и времени выполнения;
- системная инструкция сообщает модели, что она работает внутри Android, а не на Windows/ПК;
- папка-хранилище, внутри которой XaCode создаёт отдельные каталоги новых проектов;

- понятный центр разрешений при первом запуске;

## Запуск

1. Откройте проект в Android Studio.
2. Дождитесь Gradle Sync.
3. Запустите конфигурацию `app` на Android 8.0 или новее.
4. Откройте «Настройки» → «Модели и API», выберите провайдера, укажите API-ключ и нажмите «Проверить».

Для локальных серверов можно указать собственный URL. HTTP без TLS разрешён только если система или network security policy устройства это допускает; для реального использования рекомендуется HTTPS.

В настройках пользователь выбирает конкретную рабочую папку, после чего Android выдаёт приложению постоянные права только на неё.

## Сборка из терминала

```powershell
.\gradlew.bat assembleDebug
```

В проекте включены configuration cache, build cache, parallel Gradle и incremental Kotlin. После первой сборки повторный `assembleDebug` обычно выполняется за несколько секунд.

## Termux: Node.js, npm, git и другие языки

1. Установите актуальный Termux и один раз запустите его.
2. В Termux выполните `termux-setup-storage` и установите нужные пакеты, например `pkg install nodejs git`.
3. В `~/.termux/termux.properties` добавьте `allow-external-apps=true`, затем перезапустите Termux.
4. В XaCode откройте «Настройки» → «Инструменты», дайте разрешение `RUN_COMMAND` и включите «Команды через Termux».
5. Храните исполняемый проект во внутренней общей памяти Android. Облачные SAF-папки нельзя использовать как рабочую директорию Termux.

После этого агент получает инструмент `run_command` и может запускать npm-скрипты, тесты, git и установленные в Termux компиляторы.

# XaCode Android

XaCode — мобильный AI-помощник для вайб-кодинга. Просто опишите задачу: XaCode сам понимает, нужно ответить на вопрос, написать код, спроектировать приложение или создать бота.

## Первый MVP

- автоматическое понимание намерения без ручных режимов;
- локальная история разговоров;
- несколько профилей моделей и быстрый выбор модели для чата;
- DeepSeek, OpenAI, Anthropic, Google Gemini, OpenRouter, AgentRouter, Ollama и собственный API;
- просмотр, скрытие, изменение и защищённое хранение API-ключей;
- проверка подключения прямо из настроек;
- пользовательские инструкции, temperature и параметры reasoning;
- современный тёмный интерфейс на Jetpack Compose;
- поддержка OpenAI Chat Completions и Anthropic Messages API;
- API-ключи шифруются через Android Keystore, история остаётся в приватном хранилище приложения.

## Запуск

1. Откройте проект в Android Studio.
2. Дождитесь Gradle Sync.
3. Запустите конфигурацию `app` на Android 8.0 или новее.
4. Откройте «Модели и настройки», выберите провайдера, укажите API-ключ и нажмите «Проверить».

Для локальных серверов можно указать собственный URL. HTTP без TLS разрешён только если система или network security policy устройства это допускает; для реального использования рекомендуется HTTPS.
